# Creador de bingos

Aplicacion web local-first para crear, guardar y usar bingos personalizados de eventos.

## Requisitos

- Node.js 20 o superior.
- npm.

## Puesta en marcha

```bash
npm install
npm run dev
```

La aplicacion se abre en la URL que muestre Vite, normalmente `http://localhost:5173/`.

## Scripts

```bash
npm run dev
npm run build
npm run preview
```

## Persistencia

Los bingos se guardan en IndexedDB dentro del navegador. No hay backend ni cuentas de usuario en esta primera version.
